### Verification Notes
- **Authentication Gateway:** Visiting any hash route under `/index.html` without an active session immediately redirects to `/login.html`.
- **Navigation Authority:** Navigation buttons and access to modules are filtered dynamically by `user.effectivePermissions.allowedModules`.
- **Exit Admin Flow:** Administrative views (`#access` and `#depts`) expose the dedicated `← Exit Admin Panel` / `← Back to Dashboard` navigation actions which safely return to `#dash` using native hash routing without session invalidation.
- **Logout Flow:** Triggered from either the profile dropdown or the mobile drawer via `POST /api/auth/logout`.
