# Pipeline se workflow document tak

Add Card mein title likhein, Paragraph ya Heading choose karke Add block karein. Add image se PNG/JPG upload karein; caption dein. Phir Paragraph select karke neeche text add karein. Har block ke Insert below se beech mein bhi block dal sakte hain; arrows se order badal sakte hain.

Project aur Assign card to se member choose karke Create card karein. Assigned Upcoming card dashboard ke Plan stage mein khud aa jata hai. Stage click karein, task click karein: wahi document khulta hai. Page preview Word jaisi safed page layout dikhata hai. Save document changes isi browser mein rakhta hai. Unsaved document band karne par confirmation aati hai.

Print / Save PDF se A4 print view khulta hai. Uske Print button par click karke browser dialog mein Save as PDF choose karein. Text/image ka order, ownership, deadline, stage history, daily reports, checklists aur comments export mein aate hain. Existing PDF import karke edit karna aur DOCX export abhi implemented nahi hai.

Daily progress report alag hai: sirf assignment se time ya progress invent nahi hoti. Backend/database baad mein connect hoga; filhal doosre device ka data shared nahi hai.

Limits: PNG/JPG 1 MB har image, 40 blocks, document 2.5 MB total. Badi SVG paste karne ki zarurat nahi. Checks: npm run test:documents; npm run test:daily; npm run test:preview.
