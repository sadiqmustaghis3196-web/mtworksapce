# Revision aur Updates ka flow

Board mein Review ke baad Revision & Updates ka alag column hai. Reject purana alag column hi hai. In Progress, Review ya Done card par Request revision karein aur client ki instructions likhein. Drag/Move to… se bhi same form khulta hai.

Har request ka round number hota hai: Revision #1, #2 waghera. Task, document aur assignees wahi rehte hain. Revisions tab mein kaam ki update post karein. Start revision se kaam In Progress mein aata hai; phir daily work/time log karein, Send for Review aur Approve karein. Approve hone ke baad us round ki updates lock hoti hain. Naya feedback naya round banata hai; purani history delete nahi hoti.

Dashboard ka Revision & Updates lane pending revisions dikhata hai. Document preview aur Print/Save PDF mein bhi instructions, rounds aur updates dikhte hain. Creative Studio ki revision request bhi isi workflow se linked hai.

Data abhi isi browser mein hai. Real backend stage migration/database integration baad ka phase hai. Checks: npm run test:revisions; npm run test:workflows; npm run test:preview.
