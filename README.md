# MT Nexus Global — Enterprise ERP Platform

All-in-one Software House ERP, CRM, HRM, Project Management, Finance, and Team Collaboration platform for MT Nexus Global.

---

## Quick Start

### 1. Services & Ports
- **Backend API:** `http://127.0.0.1:5000` (Node.js Express / PostgreSQL 16)
- **Frontend Workspace:** `http://localhost:8000/index.html` (Vanilla HTML5 / CSS3 / ES6)
- **Login Portal:** `http://localhost:8000/login.html`
